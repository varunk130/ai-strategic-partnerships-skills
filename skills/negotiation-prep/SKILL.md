# Negotiation Prep

Walk into the room knowing what you will trade, what you will not, and who on their side actually decides.

## When to Use

- Before the first commercial conversation on a new partnership
- Before a renewal or renegotiation where the partner wants better terms
- When talks have stalled and you need to find a new trade
- When an agent platform or model provider with more leverage is setting the terms

## What You'll Need

**Critical inputs (ask if not provided):**

- The deal on the table: structure and terms, ideally from [term-sheet-builder](../term-sheet-builder/SKILL.md) with must-have / tradeable / walk-away marks
- Your alternatives if this deal does not happen
- Who you have met on the partner's side and what each has said

**Nice-to-have:**

- The partner's public strategy, earnings themes, or product roadmap signals
- History of prior deals they have done and what they conceded
- Internal approval limits (discount floor, max exclusivity, liability cap)

## Process

### Step 1: Separate interests from positions

A position is what they ask for. An interest is why. Trades happen at the interest level.

| Side | Stated position | Underlying interest | Evidence |
|------|-----------------|---------------------|----------|
| Us | | | |
| Them | | | |

### Step 2: Size each side's BATNA

| | Best alternative | Strength (1-5) | How to improve ours / weaken theirs |
|---|------------------|----------------|-------------------------------------|
| Our BATNA | | | |
| Their BATNA | | | |

Do not overstate theirs from fear or ours from pride. If you cannot name your BATNA concretely, build one before negotiating.

### Step 3: Estimate the ZOPA

For each key term, place your walk-away, your target, and your best guess at theirs. If the ranges do not overlap, the deal needs a new variable, not a harder push.

| Term | Our walk-away | Our target | Their likely walk-away | Overlap? |
|------|---------------|------------|------------------------|----------|

### Step 4: Build the give-get list

Value each item from 1 (cheap) to 5 (expensive) for each side. The best gives are cheap for you and valuable to them.

| Item | Cost to us | Value to them | Give or get | Trade for |
|------|------------|---------------|-------------|-----------|
| Example: 90-day model-change notice | 2 | 4 | Give | Minimum annual commit |
| Example: Logo rights on their agent marketplace | 1 | 3 | Get | Co-marketing launch |

### Step 5: Set anchors and the concession plan

- Open with an anchor you can justify with evidence, not just a high number
- Plan concessions in decreasing size, each tied to a get
- Never concede the same item twice; never concede without asking for something

| Round | We offer | We ask for | Fallback if refused |
|-------|----------|------------|---------------------|
| 1 (anchor) | | | |
| 2 | | | |
| 3 (final) | | | |

### Step 6: Map their stakeholders

| Role | Name / title | What they care about | Stance | Our move |
|------|--------------|----------------------|--------|----------|
| Champion | | | Supportive | Arm with internal case |
| Economic buyer | | | | Meet before final round |
| Legal | | | | Pre-share AI and data terms |
| Security / privacy | | | | Offer diligence pack early |
| Blocker | | | Opposed | Address interest, not person |

### Step 7: Write walk-away triggers

Specific, observable, agreed internally before the meeting.

## Output Format

```markdown
## Negotiation Plan: [Our company] x [Partner, e.g. Northwind Data]
Meeting: [date] | Our lead: [name] | Approver for concessions: [name]

**Our goal:** [one sentence]
**Our BATNA:** [concrete alternative] | **Their BATNA (est.):** [alternative]
**ZOPA:** [where overlap exists, and where it does not]

### Interests
| Side | Position | Interest |
|------|----------|----------|

### Give-get list
| Item | Cost to us | Value to them | Give/Get | Trade for |
|------|------------|---------------|----------|-----------|

### Anchor and concessions
1. Anchor: [offer] because [evidence]
2. Concession 2: [offer] in exchange for [get]
3. Final: [offer] in exchange for [get]

### Their stakeholders
| Role | Person | Cares about | Stance | Our move |
|------|--------|-------------|--------|----------|

```

## Guardrails

- This plan is internal. Never share it, or any version of it, with the partner.
- Do not exceed approval limits in the room. Concessions beyond them go back to the named approver.
- Do not use deception or misstate your BATNA; a long partnership outlives one negotiation.
- Stakeholder notes describe roles and interests, not personal judgments about individuals.
- Synthetic examples only.
