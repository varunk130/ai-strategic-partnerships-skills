# Partnership Renewal Review

Make the term-end call on evidence against the original thesis, not on momentum or relationship comfort.

## When to Use

- 90 to 180 days before a partnership term or auto-renewal date
- A partner asks to expand scope or change economics mid-term
- Strategy shifted and a partnership may no longer fit
- Performance has missed targets for two or more quarters

## What You'll Need

**Critical inputs (ask if not provided):**

- The original thesis and targets (business case or joint business plan)
- Actuals: pipeline, revenue, usage, joint customers
- Term end date, notice period, and termination clauses

**Nice-to-have:**

- Realized costs: people, engineering, MDF, revenue share paid
- Partner satisfaction signals and recent exec meeting notes
- List of joint customers and their dependency on the integration

## Process

### Step 1: Score performance against the thesis

Compare to what was promised, not to what seems reasonable now.

| Target | Planned | Actual | % of plan | Explanation |
|--------|---------|--------|-----------|-------------|
| Joint pipeline | | | | |
| Attributable revenue | | | | |
| Joint customers live | | | | |
| Integration adoption | | | | |
| Leading indicators hit | | | | |

### Step 2: Compare economics realized vs planned

Total investment actually spent, revenue share actually paid, return actually realized. Note where cost ran over and why.

### Step 3: Test strategic relevance now

Would we sign this partnership today? Check whether the thesis still holds, whether a better partner or build option now exists, and whether the partner's own direction still aligns (for example, Halcyon Cloud launching a competing agent).

### Step 4: Assess relationship health and switching costs

| Factor | Rating (1-5) | Evidence |
|--------|--------------|----------|
| Exec sponsorship on both sides | | |
| Commitments met by partner | | |
| Commitments met by us | | |
| Field team engagement | | |
| Customer dependency on integration | | |
| Cost to replace or rebuild | | |
| Contract exit cost | | |

### Step 5: Choose the decision

| Decision | When |
|----------|------|
| Renew | Near or above plan, thesis holds, economics fine |
| Expand | Above plan, clear next bet, both sides invested |
| Renegotiate | Thesis holds but economics or scope are wrong |
| Sunset | Thesis broken, or sustained miss with no credible fix |

### Step 6: If sunsetting, plan a respectful wind-down

Protect joint customers first. Tell the partner before the field hears it. Agree support continuity, data return, migration paths, and joint messaging. Keep the door open; ecosystems are small.

```markdown
| Notify partner exec, privately | | |

| Data return / deletion confirmed | | |

| Internal field enablement | | |
```

## Guardrails

- Do not move the original targets to make performance look better; report against what was approved.
- Never announce a sunset to customers or the field before the partner executive hears it.
- No joint customer should lose service without notice and a migration path.
- Contract interpretation goes to legal; this skill does not interpret termination clauses.
- The recommendation is input to the executive sponsor's decision.
